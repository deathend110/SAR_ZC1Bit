# SAR-ZC1Bit 实验设计书

**版本**：v1.0（定稿）  
**项目名称**：`SAR-ZC1Bit`（Zero-Crossing 1-Bit / 伪 1.5-bit SAR 成像）  
**文档定位**：指导 `SAR-ZC1Bit` 仓库搭建、阶段一规则快筛、阶段二全量独立参数校准与统计评估的总协议书。

---

## 1. 研究背景与核心命题

### 1.1 研究动机

1-bit SAR 成像仅在实/虚通道各保留 1 bit 符号（$\pm 1$），能够极大降低星载/机载/车载平台的 ADC 功耗、硬件复杂度与存储传输压力，但其强非线性截断会引入奇次谐波与量化杂波。

受近期 1.5-bit SAR 策略（Liu 等，IEEE JSTARS 2026，通过双通道模拟相移与求和构造 $\{+2, 0, -2\}$ 抑制三次谐波）的启发，本项目提出一种**零硬件改造、零额外传输比特率**的替代思路：**伪 1.5-bit 过零置零重构（Zero-Crossing Ternary Masking）**。

### 1.2 核心科学命题

> **采集端、存储端与传输端维持 100% 严格的 1-bit 数据（$\pm 1$）；仅在成像端解码前，依据相邻 1-bit 采样点的符号跳变规则将过零点位置重构为 `0`，形成 $\{+1, 0, -1\}$ 伪 1.5-bit 序列。在相同的上采样与阈值成像体系下（允许 1-bit 与伪 1.5-bit 各自独立校准最优阈值参数），验证伪 1.5-bit 方案相比原始 1-bit 在最终 SAR 图像的 PSNR、SSIM 上取得稳定提升，并在 ENL 指标上呈现出统计显著的改善。**

### 1.3 与已有工作的定位边界

* **不与双通道模拟硬件“真 1.5-bit”硬碰硬**：本项目追求的是**纯 1-bit 硬件框架内的后处理净增益**，对比基准是同上采样倍率、同阈值族下的标准 1-bit 成像。
* **聚焦四类阈值与单向主线（双向与 2D-SFT 作为后续可选）**：将 ZT、RT（SplitRT）、RSFT 与 ASFT 纳入统一单向实验协议，系统覆盖 1–9 倍距离单向与方位单向上采样；双向 BARU 与 `2D-SFT` 在底层源码中保留算子接口，调整为后续可选扩展内容。

## 2. 统一数据、信号与成像基准协议

所有对比分支必须严格锁定以下协议，防止因尺度、对齐或数据泄漏引入假结论：

| 协议项 | 锁定约定 | 说明与防漂移要求 |
| :--- | :--- | :--- |
| **样本集与划分** | 70 个配对复回波样本：35 个奇数样本为校准集，35 个偶数样本为测试集 | 参数搜索仅在 35 校准集上进行；35 测试集仅用于锁参后最终评估 |
| **矩阵维度约定** | 第 1 维（行）= 距离向 / 快时间；第 2 维（列）= 方位向 / 慢时间 | 所有 FFT 补零插值、频谱裁剪与邻值置零方向均严格遵循该约定 |
| **1-bit 量化约定** | 加阈值 $S^\uparrow + U$；非对称符号函数 $\operatorname{sgn}_+(x)=-1\,(x<0)$，$+1\,(x\ge 0)$ | 实部、虚部各自独立判决，原始 1-bit 输出严格属于 $\{1+j, 1-j, -1+j, -1-j\}$ |
| **幅度尺度估计** | $\hat\sigma = \sqrt{2/\pi}\,\mathrm{mean}(|S^\uparrow|)$ | 必须基于上采样后的复回波 $S^\uparrow$ 计算 |
| **阈值幅度参数化** | RT：$A_{\mathrm{RT}} = A_s \hat\sigma$；SFT 系列：$A_u = \hat\sigma / 10^{\mathrm{STR}_{\mathrm{dB}}/20}$ | 2D 阈值采用两方向相位相加后再取复指数，禁止复阈值直接相加 |
| **伪 1.5-bit 作用位置** | 紧接标准 1-bit 量化之后、距离压缩之前；对实部与虚部各自独立执行 | 不修改后续 `Range_Compress`、`twoDimDownsample`、`RCMC` 与 `SAR_Imaging` |
| **GT、ROI 与归一化** | 全部分支共享同一 GT、同一 ROI 与统一归一化协议 | 严禁各分支独立做不一致的 min-max 尺度处理 |
| **随机性控制** | 统一固定随机种子 `rng(seed, "twister")` 与组号映射 | 确保随机阈值（RT）可严格复现 |
| **ENL 评估协议** | `field` 与 `port` 共 20 个样本，沿用 GT 自动选定的固定 64×64 均匀区 ROI | 所有方法复用同一 ROI 坐标，保证 ENL 严格配对可比 |

## 3. 伪 1.5-bit 候选规则矩阵

记标准 1-bit 量化后某一通道（实部或虚部）的一维切片为 $b[n] \in \{+1, -1\}$（$n=1,\dots,N$）。候选方案按“过零边沿 × 置零侧”与“按位置取零（2-tap）”统一编号，便于作为 ASCII `FileKey` 与结果表主键。

### 3.1 候选规则总表

| 编号 | 规则名称 | 相邻符号变化与置零映射 | 天然 DC 偏置 | 零相位（无位移） | 分组 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| `B0` | 原 1-bit 基线 | 保持 $\{+1, -1\}$ 不变 | 无 | 是 | 基线 |
| `R1` | 双沿，双边取零 | `(+1,-1) → (0,0)` 且 `(-1,+1) → (0,0)` | **无** | **是** | **核心组** |
| `R2` | 正变负，正边取零 | `(+1,-1) → (0,-1)` | 负偏置 | 是 | **核心组** |
| `R3` | 正变负，负边取零 | `(+1,-1) → (+1,0)` | 正偏置 | 是 | **核心组** |
| `R4` | 负变正，正边取零 | `(-1,+1) → (-1,0)` | 负偏置 | 是 | **核心组** |
| `R5` | 负变正，负边取零 | `(-1,+1) → (0,+1)` | 正偏置 | 是 | **核心组** |
| `R6` | 双沿，正边取零 | 任意过零，仅将 `+1` 侧置 0 | 负偏置 | 是 | **核心组** |
| `R7` | 双沿，负边取零 | 任意过零，仅将 `-1` 侧置 0 | 正偏置 | 是 | **核心组** |
| `L1` | 无偏 2-tap 均值 | $y[n]=(b[n]+b[n+1])/2$（$n<N$），$y[N]=b[N]$；等价于双沿左侧置 0 | **无** | 否（偏移 0.5 采样点） | **核心组** |
| `R8` | 正变负，双边取零 | 仅 `(+1,-1) → (0,0)` | **无** | 是 | 补全对称组 |
| `R9` | 负变正，双边取零 | 仅 `(-1,+1) → (0,0)` | **无** | 是 | 补全对称组 |

### 3.2 阶段一附加正交开关

为避免实现细节掩盖规则本身的真实潜力，阶段一快筛引入两个正交开关：
1. **判定模式（Parallel vs. Serial）**：
   * **并行判定（默认）**：基于原始 1-bit 序列一次性标记所有满足条件的邻对再统一置 0，无扫描方向依赖，适合向量化执行；
   * **串行原地判定（对照）**：按索引顺序原地修改，前一步被置 0 的采样点不再与下一个采样点触发跳变。
2. **直流偏置校正（Raw vs. DC-Removed）**：
   * **原始输出**：保持严格的 $\{+1, 0, -1\}$ 数值；
   * **去 DC 对照**：在送入距离压缩前对实部与虚部分别减去全局均值 $Y_{\mathrm{dc}} = Y - \mathrm{mean}(Y)$，专门检验 `R2`–`R7` 等单侧规则是否仅因 DC 偏置而受损。

### 3.3 邻值作用方向定义

* **单向距离上采样**：沿距离向（dim 1）计算相邻过零。
* **单向方位上采样**：沿方位向（dim 2）计算相邻过零。
* **后续可选扩展（双向 BARU，当前暂不运行）**：源码保留 `both_union` / `both_seq_ra` / `both_seq_ar` 接口，供后续按需对比单轴与二维联合置零。

## 4. 两阶段漏斗式实验设计

为兼顾研究完备性与算力效率，实验采用“先快筛规则、再全量重校准与评估”的两阶段结构。

### 4.1 阶段一：置零规则快筛（Screening）

* **目标**：在低算力代价下摸清全部 10 种规则（8 核心 + 2 补全）及正交开关的行为特征，淘汰明显因 DC 偏置或过度置零掉点的规则，锁定 **Top 2–3 优胜规则**与默认判定/去 DC 策略。
* **测试倍率**：选取代表性总倍率 $Q \in \{1, 4, 9\}$（分别代表无上采样、中倍率、高倍率）。
* **上采样与阈值覆盖**：
  * 距离单向：`R1A1`、`R4A1`、`R9A1` × `{ZT, RT, RSFT}`（邻值沿距离向）；
  * 方位单向：`R1A1`、`R1A4`、`R1A9` × `{ZT, RT, ASFT}`（邻值沿方位向）。
* **阈值参数**：阶段一先在代表性基准参数（及 2–3 个轻量级幅度档位）下快速评估，重点对比各规则的 PSNR、SSIM、ENL、置零率（Zero Ratio）与 DC 偏置。
* **晋级标准**：综合 $Q=1,4,9$ 下的平均 SSIM、PSNR 与 $|\mathrm{ENL}-\mathrm{ENL}_{\mathrm{GT}}|$，选出表现最稳定、机制互补的 Top 2–3 规则（预期 `R1` 与 `L1` 为重点观察对象）进入阶段二。

### 4.2 阶段二：全量独立校准与两条单向主实验（Calibration & Main Evaluation）

仅对阶段一胜出的 Top 2–3 规则与基线 `B0` 展开完整 1–9 倍单向实验，划分为两条对称主线，并将双向 BARU 与 `2D-SFT` 保留为后续可选扩展：

| 实验层级 | 上采样分配（$Q \in [1, 9]$） | 参与阈值（共 4 类） | 邻值作用方向 | 核心研究问题 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 距离单向主线** | `R1A1, R2A1, ..., R9A1`（9 组） | ZT, RT, RSFT | 距离向（dim 1） | 刻画 1–9× 距离上采样下伪 1.5-bit 相对原 1-bit 的完整增益曲线 |
| **L2 方位单向主线** | `R1A1, R1A2, ..., R1A9`（9 组） | ZT, RT, ASFT | 方位向（dim 2） | 与距离向严格对称，完整评估方位单频阈值 ASFT 的协同表现 |
| **后续可选扩展（暂不运行）** | BARU $Q\in\{4,6,8,9\}$ 因子对 / `2D-SFT` | ZT, RT, RSFT, ASFT, 2D-SFT | 单轴 vs. 二维联合 | 主线闭环完成后按需启用，补充二维联合分配与二维阈值对照 |

### 4.3 独立参数重校准与消融策略（关键设计）

由于过零置零改变了有效量化增益与高频衰减特性，原 1-bit 的最优阈值参数对伪 1.5-bit 往往并非最优（例如 RT 的大 $A_s$ 或 SFT 的负 $\mathrm{STR}$ 会引发过高置零率）。因此阶段二严格执行双轨对照：

1. **各自最优上限对比（主对比）**：
   * 在 35 个校准样本上，分别为 `B0`（原 1-bit）和每个入选伪 1.5-bit 规则独立寻优：
     * **ZT**：无自由参数，直接评估；
     * **RT（SplitRT）**：一维搜索幅度系数 $A_s$（覆盖从弱抖动到强抖动区间）；
     * **RSFT**：二维搜索 $(\mathrm{STR}, f_r/B_r)$；
     * **ASFT**：二维搜索 $(\mathrm{STR}, f_a/B_a)$；
     * *（可选扩展）* **2D-SFT**：三维搜索 $(\mathrm{STR}, f_r/B_r, f_a/B_a)$。
   * **选优准则**：按校准集平均 **SSIM 最大**选定最优参数，并列时以平均 **PSNR 最大**破局；锁定参数后在 35 个测试样本上计算最终指标。
2. **原参数直迁消融（辅助对比）**：
   * 将原 1-bit 锁定的历史最优参数直接套用于伪 1.5-bit，用于定量剥离“置零算子本身带来的即插即用增益”与“阈值参数重适配带来的额外增益”。

## 6. 仓库架构与工程规范（对齐 `SAR-Dataset-Transformer`）

新仓库 `SAR-ZC1Bit` 不沿用旧 BRAU 单脚本结构，完全参照 `SAR-Dataset-Transformer` 的模块化工作流设计：

### 6.1 目录职责划分

| 路径 | 职责与内容 |
| :--- | :--- |
| 根目录 `start_zc1bit.m` | 面向交互式运行的一键入口脚本（顶部参数区选阶段、阈值、倍率与缓存上限），调用统一工作流，不写重复逻辑 |
| 根目录 `zc1bit_config.m` / `zc1bit_smoke_config.m` | 完整实验配置与轻量冒烟测试配置分离 |
| 根目录 `setup_zc1bit_paths.m` | 统一路径注入 |
| 根目录 `run_zc1bit_{screen,search,confirm,evaluate,workflow}.m` | 阶段一快筛、参数搜索、锁参确认、测试集评估与全流程串联公共入口 |
| `src/compat/` | 复用加性复高斯噪声 `gaussian.m` 与图像归一化 `normalize_image.m` |
| `src/sampling/` | 距离、方位与双向 BARU 的网格解析、FFT 补零插值与频谱裁剪 |
| `src/threshold/` | 统一封装 ZT、RT（SplitRT）、RSFT、ASFT、2D-SFT 阈值构造与 $\hat\sigma$ 估计 |
| `src/quantization/` | 标准 1-bit 量化与伪 1.5-bit 过零置零算子族（统一支持 `R1`–`R9`、`L1`、并行/串行、去 DC 与方向参数） |
| `src/sarproc/` | 复用 `Range_Compress`、`RCMC`、`SAR_Imaging`、`generate_gt_image` 与 ROI 索引模块 |

| `src/workflow/` | 搜索会话缓存、按“候选×场景”原子保存 checkpoint、仅核对实际计算参数的断点恢复、锁参表读写与报表生成 |
| `inputs/reference/` | 存放原 1-bit 历史锁定参数参考表（用于直迁消融对照） |
| `tests/` | 不依赖外部大数据的轻量单元测试（覆盖 `R1`–`R9`/`L1` 真值表、无 DC 性质、边界长度保持、工作流冒烟测试） |

| `results_zc1bit/` | 按阶段分目录落盘（`screen/`、`search/`、`locked/`、`evaluate/`、`stats/`、`figures/`） |
| `AGENTS.md` & `README.md` | 沿用既有 MATLAB 防回归规范、UTF-8 编码要求及“实现授权与运行授权分离”约定 |

### 6.2 关键工程防回归要点

* **单核内存优先与机械盘低 I/O 约束**：面向单机机械硬盘、32 GB 内存工作环境，工作流保持单核单会话执行（不启用 MATLAB 并行池 `parpool`，避免进程间大矩阵复制）；存在未完成任务时，对 7 个回波文件**仅顺序读取 1 轮**将 35 个校准基带块（约 403 MB）常驻内存；外层按 `(Range_q, Azimuth_q)` 分组并在 `cfg.runtime.cache_gb`（默认 `5` GB，4–6 GB 区间）预算内整组缓存 `signal_up` 复用（超预算时自动回退流式单样本复用），避免反复上采样 FFT 与重复读盘。
* **Checkpoint 恢复原则**：阶段一按 `ThresholdKey`（35 样本整体）在扁平目录 `checkpoints/screen/<ThresholdKey>.mat` 原子落盘，`< 1.5 GB` 载荷默认使用 `-v7` 格式（避免逐场景/逐样本高频小文件写入与 HDF5 元数据寻道开销）；恢复时仅核对实际计算参数（倍率、阈值类型与参数、置零规则 Key、样本划分、归一化口径），不因路径、`runtime.cache_gb`、`preload_signals`、时间戳或版本号变化而失效。
* **零泄漏与零漂移**：禁止从未完成的搜索 cube 中提前选优；所有倍率、规则名与 CSV 输出使用稳定的 ASCII `FileKey`；`table` 构造、数组方向（`(:)` 对齐）及 `signrank` 调用遵循 `AGENTS.md` 防回归清单。

## 7. 预期风险与应对预案

| 潜在风险 | 物理成因 | 实验中的观测手段与应对 |
| :--- | :--- | :--- |
| **RT 阈值下置零率过高** | 随机相位抖动使相邻采样点高频翻号，`R1` 下置零率可能逼近 75% | 重点观察 `Zero Ratio`；在阶段二放宽 $A_s$ 搜索下界（如向下探索小 $A_s$），同时对比单侧置零的 `L1` |
| **单侧规则 `R2`–`R7` 掉点** | 仅置零 `+1` 或 `-1` 引入显著直流偏置，污染 LFM 基带零频 | 通过阶段一“去 DC 对照”明确归因，区分规则本质与偏置影响 |
| **`L1`（2-tap）在 $Q=1$ 吃亏** | 2-tap 引入 0.5 采样点群延迟，在无上采样时造成半像素微移 | 与零相位对称的 `R1` 同场对比；观察随 $Q$ 增大（偏移缩小至 $0.5/Q$ 像素）后 `L1` 是否反超 |
| **SFT 强载波主导过零** | 负 $\mathrm{STR}$ 下阈值幅度大于回波，过零点由单频载波而非信号主导 | 通过阶段二独立重校准，允许 $(\mathrm{STR}, f/B)$ 向更高 $\mathrm{STR}$ 或更低频比自适应偏移 |
