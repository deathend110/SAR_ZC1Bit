# SAR-ZC1Bit 实验协议（唯一约束基线）

> 本文档定义 `SAR-ZC1Bit` 仓库的实验主题、硬性目标与不可变更的评估口径。所有脚本、搜索、评估与报表必须严格遵守本协议，保持简洁高效，禁止范围蔓延。

## 1. 实验主题与核心目标

* **实验主题**：面向纯 1-bit SAR 回波的**过零置零伪 1.5-bit 重构**（采集与传输严格保持 $\pm 1$，零额外硬件与比特开销；成像前将邻点过零位置重构为 `0`，形成 $\{+1, 0, -1\}$）。
* **核心目标**：在 ZT、RT（SplitRT）、RSFT、ASFT 四类阈值与 1–9 倍单向上采样（距离单向与方位单向）下，以原始复回波成像为 GT，验证伪 1.5-bit 方案（各自独立校准最优阈值参数）相比原始 1-bit 成像在 **PSNR、SSIM** 上稳定提升，并在 **ENL** 上呈现统计显著改善。
* **明确不做 / 后续可选**：当前主实验不引入双通道硬件“真 1.5-bit”仿真，不引入深度学习恢复模块，不修改下游 SAR 成像算法（`Range_Compress` / `RCMC` / `SAR_Imaging`）；**双向上采样（BARU）与 2D-SFT 调整为后续可选扩展，不纳入当前必做主实验**。

## 2. 不可变更的基准口径

| 项目 | 锁定口径 |
| :--- | :--- |
| **样本划分** | 70 样本：35 奇数样本校准集，35 偶数样本测试集（测试集严禁参与寻优） |
| **维度约定** | dim 1 = 距离向（快时间），dim 2 = 方位向（慢时间） |
| **1-bit 量化** | 加阈值 $S^\uparrow + U$，$\operatorname{sgn}_+(0)=+1$，I/Q 独立判决 |
| **幅度尺度** | $\hat\sigma = \sqrt{2/\pi}\,\mathrm{mean}(|S^\uparrow|)$（基于上采样后回波） |
| **伪 1.5-bit 注入点** | 紧接 1-bit 量化后、距离压缩前；I/Q 各自独立处理，尺寸不变 |
| **GT 与归一化** | 全部分支共享同一 GT、同一 ROI 与统一归一化协议 |
| **ENL 口径** | `field` + `port` 共 20 样本，复用 GT 自动选定的固定 64×64 均匀区 ROI |

## 3. 候选置零规则集合（ASCII `FileKey`）

对标准 1-bit 通道切片 $b[n]\in\{+1,-1\}$（$n=1,\dots,N$）：

| Key | 规则定义 | 分组 |
| :--- | :--- | :--- |
| `B0` | 原 1-bit（$\pm 1$ 不变） | 基线 |
| `R1` | 双沿，双边取零（`+1,-1 → 0,0` 且 `-1,+1 → 0,0`） | **核心组** |
| `R2` | 正变负，正边取零（`+1,-1 → 0,-1`） | **核心组** |
| `R3` | 正变负，负边取零（`+1,-1 → +1,0`） | **核心组** |
| `R4` | 负变正，正边取零（`-1,+1 → -1,0`） | **核心组** |
| `R5` | 负变正，负边取零（`-1,+1 → 0,+1`） | **核心组** |
| `R6` | 双沿，正边取零（任意过零仅 `+1` 置 0） | **核心组** |
| `R7` | 双沿，负边取零（任意过零仅 `-1` 置 0） | **核心组** |
| `L1` | 无偏 2-tap（$y[n]=(b[n]+b[n+1])/2$，$y[N]=b[N]$；双沿左侧置 0） | **核心组** |
| `R8` | 正变负，双边取零（仅 `+1,-1 → 0,0`） | 补全对称组 |
| `R9` | 负变正，双边取零（仅 `-1,+1 → 0,0`） | 补全对称组 |

* **阶段一正交开关**：（1）**并行判定**（默认）vs. **串行原地判定**；（2）**原始输出** vs. **去 DC**（$Y - \mathrm{mean}(Y)$）。

## 4. 两阶段精简执行约束

1. **阶段一：快筛（`screen`）**
   * 范围：$Q\in\{1, 4, 9\}$，距离单向（`R1A1, R4A1, R9A1` × `{ZT, RT, RSFT}`，邻值沿 dim 1）与方位单向（`R1A1, R1A4, R1A9` × `{ZT, RT, ASFT}`，邻值沿 dim 2），共 36 组阈值配置。
   * 产出：淘汰低效规则，锁定默认判定/去 DC 策略，选出 **Top 2–3 优胜规则**进入阶段二。
2. **阶段二：全量重校准与评估（`search → confirm → evaluate`）**
   * 仅对 `B0` 与阶段一胜出的 Top 2–3 规则执行两条单向主实验：
     * **L1 距离主线**：`R1A1 ~ R9A1` × `{ZT, RT, RSFT}`（邻值沿 dim 1）；
     * **L2 方位主线**：`R1A1 ~ R1A9` × `{ZT, RT, ASFT}`（邻值沿 dim 2）；
     * **后续可选扩展（原 L3，当前暂不运行）**：双向 BARU（$Q\in\{4,6,8,9\}$ 因子对）与 `2D-SFT` 专题，待主实验完成后按需启用。
   * **公平校准**：`B0` 与伪 1.5-bit 在 35 校准集上**各自独立寻优**（平均 SSIM 优先，PSNR 破局），并保留“原 1-bit 参数直迁”作消融。

## 5. 必出指标与验收底线

* **主指标**（35 测试样本）：PSNR (dB)、SSIM。
* **均匀区指标**（20 样本固定 ROI）：ENL 及 $|\mathrm{ENL}-\mathrm{ENL}_{\mathrm{GT}}|$。
* **诊断与辅助**：Entropy（256-bin）、置零率（Zero Ratio）、I/Q 均值偏置、典型样本距离压缩带外能量比。
* **显著性检验**：所有“伪 1.5-bit 减 `B0`”配对差值执行双侧配对 **Wilcoxon 符号秩检验**，输出均值、标准差与 $p$-value。
* **验收底线**：完整输出须通过 `checkcode`、`tests/` 单测及逐样本表维度/非有限值检查，并保留完整 metadata 以便复现。
